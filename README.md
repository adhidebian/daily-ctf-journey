# daily-ctf-journey
My daily CTF practice with solutions, notes, techniques and lessons learned while developing practical cybersecurity skills.

Daily CTF Journey
This repository contains my daily Capture The Flag (CTF) practice and the notes I take when solving different cybersecurity challenges.
I created this repo to keep track of my progress, to document what I learn and to build up my practical cybersecurity skills with regular hands-on practice.
I do CTF challenges every day which are in different fields of Cybersecurity. I document the approach that I took to understand and solve the challenge, alongwith the tools, commands, techniques and important concepts that I learned.The main goal of this repository is to collect flags but also to learn how and why each challenge works.
